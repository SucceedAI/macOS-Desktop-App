SucceedAI Support

How can we help?

Get direct help with SucceedAI on iPhone, iPad or Mac. Tell us what happened and we will help you get back to private, on-device writing.

Email SucceedAI Support Report a technical issue

Support email: hi@ph7.me. Please allow up to two business days for a reply. Do not include confidential source text, prompts or generated results.

Before you contact us

  • Include your SucceedAI version and operating-system version.
  • Tell us whether you use iPhone, iPad or Mac.
  • Describe the action you selected and the exact error message.
  • Do not send private writing or personal information.

Device requirements

SucceedAI requires iOS, iPadOS or macOS 26 on a device that supports Apple Intelligence. Apple Intelligence must be enabled and its on-device model must be ready.

Generation happens locally. SucceedAI has no account, subscription, backend server or third-party AI key.

Mac setup

  1. Open SucceedAI from the menu bar.
  2. Copy the text you want to improve.
  3. Choose Use Copied Text.
  4. Select Proofread, Polish, Shorten, Draft Reply, Summarize, Action Items, Make a Plan, Change Tone or Translate.
  5. Choose Generate, then Copy when the result is ready.

SucceedAI does not request Accessibility or Input Monitoring permission and does not monitor keystrokes.

iPhone and iPad setup

Write directly in the app or enable the optional SucceedAI keyboard in Settings. The keyboard does not request Full Access.

To dismiss the keyboard in the main app, tap Done above the keyboard or tap outside the editor.

Local AI is unavailable

  • Confirm Apple Intelligence is enabled in Settings or System Settings.
  • Connect the device to power and Wi-Fi if the model is still downloading.
  • Restart SucceedAI after Apple Intelligence reports that it is ready.
  • Try a shorter source text if generation cannot finish.

Privacy and source code

Prompts and results stay on the device. Read the privacy policy for details.

Developers can inspect the project, report a reproducible issue or contribute through the SucceedAI GitHub repository.
