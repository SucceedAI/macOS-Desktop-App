Support

Use this page as the support destination for the App Store listing and GitHub Pages launch site.

Common Setup Steps

  • Open SucceedAI from the macOS menu bar.
  • Copy the text you want to proofread, rewrite, summarize, translate, or turn into a plan.
  • Choose Use Copied Text. Clipboard text is read only after you choose this button.
  • Choose an outcome, select Generate, review the result, then choose Copy Result.
  • Confirm Apple Intelligence is enabled if the local model is unavailable.

Permissions

SucceedAI does not require Accessibility or Input Monitoring permission on macOS. It does not monitor keystrokes or control other apps.

Need Help?

Open a GitHub issue with your macOS version, SucceedAI version, the outcome you selected, and any error shown by the app. Do not include private source text.
